Échanger deux valeurs

Avec le même tableau tab, demandez deux indices et échangez les valeurs placées à ces deux indices.
Si un indice n’existe pas dans le tableau, affichez un message d’erreur.
Exemple:
Indices : 0 et 3
Avant : [12, 15, 13, 10, 8, 9, 13, 14]
Après : [10, 15, 13, 12, 8, 9, 13, 14]
Ouvrez la console avec F12 pour voir le résultat.
